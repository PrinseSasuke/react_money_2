# Сравнение: predict_linear() vs Chronos-Bolt — эксперимент "лестница"

Под: `backend-8fd64c8cc-rcm8x`. Лимит контейнера: 256Mi (268.44 MB). Лестница: 40 → 80 → 120 → 160 → 200 MiB, по 40 сек на шаг (13:37:05–13:40:26 UTC), затем восстановление.

## Итоговая таблица

| Метод | Момент срабатывания (UTC) | Реальное значение метрики в этот момент | Что означает |
|---|---|---|---|
| **Фактический пик** | 13:40:20–13:40:30 | 240.3 MB (89.5% от лимита) | Реальный максимум за эксперимент — лимит физически не превышен (специально) |
| **predict_linear() (PromQL)** | **13:39:50** | 198.0 MB (73.8% от лимита) | Прогноз на 60 сек вперёд впервые показал будущее превышение лимита (275.5 MB) |
| **Chronos-Bolt (предобученная модель)** | — | — | **Не выполнено** — заблокировано окружением, см. блокер ниже |

**Lead time predict_linear() относительно фактического пика: ~40 секунд.** Модель дала бы сигнал тревоги за 40 секунд до того, как память достигла своего максимума за эксперимент — и это при том, что в момент сигнала реальное значение было ещё далеко от опасной зоны (74%, не 90%+).

## Честная оговорка

Память в этом прогоне **не превысила** лимит контейнера физически (пик — 89.5%) — эксперимент специально спроектирован как контролируемый, без реального падения пода. Поэтому "реальный момент опасности" в таблице — это фактический пик нагрузки, а не момент отказа. Вывод про lead time от этого не становится менее честным: `predict_linear()` среагировал на **тренд**, а не на факт — именно это и является предметом исследования.

## Блокер: Chronos-Bolt не установлен

```
ERROR: Could not find a version that satisfies the requirement chronos-forecasting (from versions: none)
ERROR: No matching distribution found for chronos-forecasting
```

Причина: сервер на Ubuntu 20.04.6 LTS с Python 3.8.10 (системный, единственный доступный) — `chronos-forecasting` требует более новый Python. Попытка поставить Python 3.11 через `deadsnakes` PPA:
```
E: Unable to locate package python3.11
```
PPA `deadsnakes` подключился без ошибок (репозиторий обновился, GPG-ключ в порядке), но пакетов под `focal` (Ubuntu 20.04) для актуальных версий Python в нём больше нет — Ubuntu 20.04 официально не поддерживается (EOL), и мейнтейнеры deadsnakes, похоже, прекратили сборку под неё.

**Решение не найдено в рамках "быстрой проверки"** (компиляция Python из исходников — совсем другой по времени объём работы, не соответствует духу этого эксперимента). Зафиксировано как честный блокер, не подгонялось.
