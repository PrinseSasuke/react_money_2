## Как читать эту документацию

- Архитектурные разделы (01, 04, 08) написаны простым языком — для человека со стороны.
- Референсные разделы (02, 03) — точный технический язык, сверены с реальным кодом на момент написания.
- Всё, что помечено **"запланировано, не реализовано"** или **"частично"** — так и есть по факту, ничего не приукрашено.
