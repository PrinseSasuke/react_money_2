# Редизайн фронтенда на MUI + Tailwind — статус

Ветка: `redesign/mui-tailwind` (в `main` не вливалась, на прод не деплоилась).
Backend, API и БД не менялись; все вызовы идут через прежний `src/services/api.js`.

Все страницы и компоненты переехали на новый стек. Старых SCSS-модулей, системы тем на CSS-переменных и прежних UI-зависимостей в проекте больше нет.

## Что сделано по фазам (коммиты в ветке)

1. **Стек.** MUI 7 + MUI X 8 (графики, датапикеры на dayjs) + Tailwind 3.
   - Единственный reset — `CssBaseline` из MUI; `preflight` у Tailwind выключен.
   - `StyledEngineProvider injectFirst`: стили MUI вставляются первыми, Tailwind-утилиты могут их перекрывать.
   - Tailwind используется для layout (flex/grid/отступы/адаптив), а цвета, типографика и компоненты берутся из MUI-темы.
   - Тема: `createTheme` с `palette.mode: 'light' | 'dark'`, акцент `#4E36FC`, шрифт Inter, скругления 12–20px, мягкие тени карточек, русские локали MUI и датапикеров.
2. **Каркас.** На десктопе постоянный сайдбар, на мобильных — выезжающий Drawer; липкая шапка с переключателем темы и меню пользователя. Выбор темы хранится в `localStorage` (ключ `theme`, как раньше) и дублируется атрибутом `html[data-theme]`.
3. **Авторизация.** Экран из двух колонок: слева брендовая панель, справа форма. Добавлены показ пароля и необязательное имя при регистрации.
4. **Дашборд и операции.**
   - Дашборд: виджеты сводки, график доходов и расходов за 6 месяцев, последние операции, календарь, список счетов.
   - Операции: таблица на десктопе, карточки на мобильном, поиск, фильтр по типу, сортировка, пагинация, меню действий, открытие операции двойным кликом.
5. **Остальные разделы** — по одному коммиту на раздел. Графики переведены с `react-google-charts` на MUI X Charts: они сами подхватывают тему и не грузят скрипты с серверов Google.
6. **Полировка и адаптив.**
   - Проверены 360/390px, планшет и десктоп 1440px, обе темы.
   - Автоматически проверено, что на ширине 360px ни на одной странице нет горизонтальной прокрутки.
   - В ячейках календаря на телефоне показываются номер дня и компактная сумма (`+120к`), на десктопе — `ДД.ММ`.
7. **Чистка.** Удалены все `*.module.scss`, `App.scss`, старые компоненты и хуки, неиспользуемые картинки из `public/img`, а также зависимости `react-modal`, `react-datepicker`, `react-day-picker`, `react-google-charts`, `sass`, `web-vitals`.

## Исправления, найденные по ходу

- **Разлогин при сбое сети.** Раньше `AuthContext` удалял токен при любой ошибке `/auth/me`, поэтому обрыв сети или рестарт бэкенда выкидывали пользователя. Теперь токен удаляется только на 401/403, в остальных случаях запрос повторяется.
- **Ложно-зелёные a11y-тесты.** E2E-проверки доступности главной и списка операций на самом деле проверяли страницу логина: сессию выбивало, а тест этого не замечал. Теперь хелпер входа проверяет, что приложение открылось, и axe нашёл реальное нарушение (`<a>` прямо внутри `<ul>` в меню). Исправлено.
- **Прогноз при одном месяце данных.** Линейная регрессия делила на ноль, и прогноз был `NaN`. Теперь это случай обработан.
- **Значок вложения после правки.** После редактирования операции значок вложения (📎) пропадал: ответ `PUT` не содержит `attachment_count`, теперь он сохраняется из текущей строки.
- **Импорт из Excel.** После импорта общий список операций не обновлялся до перезагрузки страницы. Теперь обновляется сразу.
- **Регистр путей.** Новая папка `components/stats` совпадала с существующей `components/Stats` на Windows: сборка на Linux бы упала. Папка переименована в `components/statistics`, и все импорты проверены скриптом на точный регистр.

## Решения по дизайну, принятые самостоятельно

Figma-референс Maglo использован как ориентир по компоновке и настроению, без копирования графики и цветов.

- **Сайдбар светлый** (в тёмной теме — тёмный), активный пункт выделен заливкой фирменного фиолетового. Брендовый цвет достаточно насыщенный, поэтому залитый сайдбар спорил бы с акцентной карточкой баланса.
- **Первый виджет залит градиентом** в фирменных цветах, остальные белые — как в референсе.
- **Контраст.** Цвета доходов и расходов подобраны под WCAG AA и для текста, и для «мягких» чипов. В тёмной теме акцент светлее (`#8B7DFF`), а заливка основных кнопок на тон темнее, чтобы белый текст на них оставался контрастным.
- **Динамика в процентах.** На главной сравнивается «месяц на сегодня» с тем же отрезком прошлого месяца. В статистике — период с предыдущим периодом той же длины.
- **Иконки категорий** взяты из `@mui/icons-material`, каждой категории назначен свой цвет. Эти же цвета используются в донат-графиках.
- **Период статистики** по умолчанию — «этот месяц» (раньше «вчера–сегодня»). Добавлены пресеты 7/30 дней и «этот год». Диапазон задаётся двумя датапикерами, потому что DateRangePicker в MUI X платный (Pro).
- **Сортировка операций** по умолчанию «сначала новые», чтобы только что добавленная операция была на первой странице, а не в конце списка.
- **Привязка Telegram** перенесена со страницы лимита в «Настройки». На странице лимита осталась ссылка туда.
- **Календарь** собран на собственной сетке месяца. В `DateCalendar` из MUI ячейки дня слишком маленькие, чтобы уместить сумму.

## Известные ограничения

- **Размер бандла.** JS после gzip вырос примерно на 150 КБ (≈460 КБ, в основном MUI X Charts и датапикеры). Если это критично, следующий шаг — ленивая загрузка страниц с графиками (`React.lazy`).
- **Визуальные baseline снимались на Windows.** В CI визуальные тесты по-прежнему исключены (`--grep-invert "visual regression"`), как и раньше: рендер шрифтов в Linux отличается.

## Проверка

- `npm run build` — сборка без предупреждений.
- Юнит-тесты утилит: `npx react-scripts test --watchAll=false`, 4/4.

## Как посмотреть локально

```bash
git fetch origin
git checkout redesign/mui-tailwind
npm install
```

Бэкенд с базой (как обычно):

```bash
docker compose up -d postgres backend
```

Бэкенд должен быть доступен на `localhost:4000`. Локально это обеспечивает файл `docker-compose.override.yml`, который публикует порт 4000.

Запуск фронтенда:

```bash
npm start
```

Если порт 3000 занят, задайте другой: `PORT=3100 npm start`.

Прогон тестов (нужна тестовая БД на порту 5433):

```bash
docker compose -f docker-compose.test.yml up -d
npx playwright test --grep-invert "visual regression"
npx playwright test e2e/visual.spec.js
```

Если порт 3000 занят, перед командами Playwright задайте `E2E_WEB_PORT=3100`.
