# research/ — ML-обнаружение атак по метрикам (изолированный трек для статьи)

Этот каталог — **отдельный исследовательский трек**, физически и организационно
изолированный от основной дипломной работы (`backend/`, `frontend/`, `k8s/`,
`scripts/chaos_run.py` и т.д.). Здесь разрабатывается подсистема генерации
**размеченного датасета** «норма / сбой / атака» на изолированном стенде и
сравнение ML-детекторов для научной статьи.

> **Контекст работ — авторизованное исследование безопасности.** Все сценарии
> запускаются **только против собственного приложения `react-money` на
> собственном изолированном k3s-стенде**, в выделенных namespace'ах, без доступа
> в интернет из атакующих подов. Цель — не компрометация, а генерация телеметрии
> для обучения детекторов. Используются признанные инструменты (Chaos Mesh,
> Stratus Red Team, sqlmap, hydra, k6), а не самописные эксплойты.

## Быстрый старт (после разработки)

```bash
git checkout research/ids-ml     # отдельная ветка, см. RULES.md
cd research
./labctl doctor                  # проверка изоляции стенда
./labctl scenario run baseline   # эталонный прогон "норма"
./labctl scenario run all        # весь план: норма + сбои + атаки
./labctl dataset build           # собрать размеченный CSV из Prometheus
./labctl model train             # обучить и сравнить детекторы
```
