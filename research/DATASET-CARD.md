**Как различаются двойники:**
- **flash-crowd vs флуд** (оба ↑rps): flash-crowd грузит БД (pg_tps высокий — легитимные юзеры к /me), флуд — нет (бьёт по /health).
- **authfail vs brute-force** (оба ↑401): brute грузит БД (login делает SELECT users), authfail — нет (401 отдаётся до БД в requireAuth).
- **netdelay vs флуд**: netdelay даёт ↑задержку и ↓rps; флуд — ↑↑rps. Противоположное направление rps.

## Ограничения

1. **Класс attack — меньшинство** (~11%): атаки короче сбоёв. Компенсируется class weights/стратификацией при обучении.
2. **kill-backend слабо заметен**: self-healing ~6с; агрегат min частично помогает.
3. **Двойник-сбой для SQLi (устойчивый 5xx) отсутствует**: на стенде отказ БД даёт зависание/499, HTTPChaos не инжектится — отложено.
4. **boundary-окна** на стыках помечены (по умолчанию исключаются из train).
